# Brief: anime-webui-redesign

## Goal

把 `static/index.html`（FastAPI 直接返回的单页界面）从深色灰板改成**日式二次元**外观：用户提供的 3840×2160 动漫插画作为整页背景，界面在其上以玻璃/纸张材料保持运维工具的可读性与可扫读性。功能、DOM id、`/api/*` 契约、1.5s 轮询、全部按钮行为**不变**；本次只换界面皮肤与信息层级。

## Audience

学生本人在自己的 Windows 电脑上使用，浏览器开 `http://127.0.0.1:8900`，微信 PC 端在同一台机器。使用压力：首次配置（装 CA、开代理）时有不确定感，抓包列表为空时容易以为坏了，批量下载时想一眼看清谁在下、谁失败、失败原因是什么。

## Visitor mode

`Operate`。成功条件：看一眼就知道「现在处于四步流程的哪一步」以及「哪些条目可以下、哪些失败、失败后该做什么」，不需要读文档。

## Surface

- 1 个页面（`static/index.html`），桌面 1440×900 为基准，1280 宽与 ≥1920 宽都不破版；窄屏（≤820px）单列可用。
- 组件：状态胶囊、四步流程条、工具栏、条目标签、进度条（确定/不确定）、操作按钮组、输入框、空态、错误文案、破坏性操作确认。
- 状态覆盖：抓包运行/未运行、代理开/关、证书已信任/未安装/未生成、条目 未下载/排队中/下载中/完成/失败/已取消、已忽略、TS 分片与「下载整节课」、空列表、接口异常。

## Constraints

- 无构建步骤、无外部字体/图标库/CDN；`style` + `<script>` 内联在同文件。
- 不改后端 `/api/*`；仅新增一条只读静态资源路由用于提供背景插画。
- 中文界面：系统 CJK 字体栈，正文 14px，行高 1.5–1.75，标点全角，数字等宽对齐。
- 插画为用户提供的素材（© HoYoverse 官方插画），**仅本机个人离线学习使用，不再分发**；在 `DESIGN.md` 记录授权与替换点。
- 动效最小化，遵守 `MOTION.md`（posture: minimal）与 `prefers-reduced-motion`。

## Non-goals

- 不做营销页 / hero / 落地页结构；不引入向导式分步流程（后端起止是异步的，向导会撒谎）。
- 不改信息架构、不上前端框架、不加路由、不加重试/遥测/日志等未要求的能力。
- 不重写下载引擎、代理开关、数据库；不动 `wxc/` 下除新增只读路由以外的代码。

## Real content ranges

- 标题最短「线性代数 · 第1章」，最长「马克思主义基本原理概论 · 第七章 共产主义崇高理想及其最终实现 · 第3讲」（长标题必须省略号截断 + `title` 全量）。
- 数量：0 条（空态）、12 条（常见）、300+ 条（表格容器自身滚动，表头吸顶）。
- 缺失：未命名条目、无 host、无尺寸（`—`）、未知 kind。
- 混合脚本：`HLS`、`1280x720`、`127.0.0.1:8899`、`ffmpeg`、`mp4` 与中文混排。
- 权限受限：文件名/路径可能很长且含空格与中文。

## Acceptance checks

1. 背景插画可见（不糊、不被完全遮住），表格正文与背景插画上任意像素的对比度 ≥ 4.5:1。
2. 四步流程条随 `/api/status` 实时点亮：CA 证书 → 系统代理 → 抓包运行 → 有可下载条目。
3. 失败条目显示可执行的原因文案（重新播放该课时再抓一次），而非只显示错误码。
4. 键盘可达：Tab 顺序 = 视觉顺序，`:focus-visible` 清晰，标题改名 Enter 提交、Esc 取消。
5. `prefers-reduced-motion: reduce` 下无旋转/过渡，进度仍有文字表达。
6. 1440×900 与 820px 宽：无重叠、无裁字、无横向滚动条（表格容器内部滚动除外）。

## Playground applicability

Waived：本变更的界面本身就是可直接在浏览器里操作的真界面（真数据、真状态），再做一层 Playground 只会复制同一个界面。交互探索用浏览器直接跑 `wxc ui` 完成。
