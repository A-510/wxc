# Directions

来源：`direction-previews/index.html`（三候选，同一份 `content-fixture.json` 真实内容与状态覆盖，同一视口
1440×900，每候选一张截图并已哈希，见 `direction-preview.json`）。选择由用户在三张截图中做出，
`direction check --stage selection` 已 `ready`。

## 选定：③ poster-pop · 海报波普

- **视觉论点**：米黄纸 `#fbf3e4` + 半调网点打底；用户提供的 3840×2160 插画裁成一张**顶部海报条**
  （`center top / cover`，3px 墨框 + 6px 硬投影），插画以完整构图出现而不承字；界面材料是纸（`#fffdf6`）
  与墨（`#231c12` 2px 线 + 硬投影），印刷双色为青 `#1597b4` 与洋红 `#c62d6d`；标题墨块、虚线铅印表格。
- **交互论点**：四步流程做成四张**数据绑定的印刷号码牌**（吃 `/api/status` 的 `cert.installed`、
  `proxy.enabled`、`counts.total`、`counts.done`）；按下按钮下沉 1.5px 并撤掉硬投影（瞬时状态替换）；
  表格容器内滚动、表头吸顶；下载中不确定比例用一个旋转弧（`transform.orbit`，900ms 顺时针）。
- **适配**：用户要「日式二次元」并提供了插画 → 海报条让插画成为完整画面；运维工具主线（证书→代理→抓包→
  下载）是线性顺序 → 号码牌正好表达顺序；正文全部落在纸上，可读性不依赖插画像素。
- **风险**：海报条占掉约 172px 首屏高度，同屏行数少于 sky-glass；纸感重，长时间密集扫读略累。已接受。

## 落选（各一句，作为诚实备选保留）

- **① sky-glass · 空色玻璃**：插画全幅铺底当「窗外天空」，文字落在 88% 奶油色磨砂玻璃上，四步是四珠节奏
  轨道。首屏表格行数更多，但每个面板都要用不透明度去换对比度，材料复杂度高；用户未选。
- **② dusk-ink · 暮色墨**：插画压到 16% 当底纹，深靛紫控制台 + 左侧竖轨 + 12.5px 密集表格，同屏 8 行，
  扫读最快；插画几乎不可见，与「用我给的插画做二次元界面」冲突；用户未选。

选定结果已写入 `DESIGN.md`（界面身份）与 `MOTION.md`（动效语言），实现见 `static/index.html`。
